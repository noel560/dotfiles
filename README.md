## ✨ Features
- **Hyprland configuration**
- **Waybar theme** [Credits: elifouts](https://github.com/elifouts/Dotfiles)
- **Rofi theme**
- **Sddm theme** [Credits: Keyitdev](https://github.com/Keyitdev/sddm-astronaut-theme)
- **Wlogout theme** [Credits: maxhu08](https://github.com/maxhu08/dotfiles)
- **Pywal integration everywhere**  
- **Swaync theme**
- **Alacritty theme**

## 🚀 Installation
```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/noel560/dotfiles/main/install.sh)"
```
